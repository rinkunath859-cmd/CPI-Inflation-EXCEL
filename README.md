# 📊 CPI Inflation Analysis Using Microsoft Excel

## 📌 Project Overview

This project analyzes India's Consumer Price Index (CPI) using Microsoft Excel to identify inflation trends, understand category-wise contributions, examine the impact of COVID-19, and explore the relationship between crude oil prices and CPI.

The project demonstrates Excel-based data cleaning, Pivot Tables, Pivot Charts, dashboard development, and business analysis to derive actionable insights.

---

## 🎯 Objectives

- Analyze overall CPI inflation trends.
- Identify major contributors to inflation.
- Study Year-over-Year inflation.
- Analyze food inflation patterns.
- Compare inflation before and after COVID-19.
- Evaluate the relationship between crude oil prices and CPI.

---

## 📂 Dataset

**Source:** National Statistical Office (NSO), Government of India

**Dataset:** Consumer Price Index (CPI)
